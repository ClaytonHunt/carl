# CARL Development Project

## Description

CARL (Coding Assistant for Rapid Launch) is an AI-powered development orchestration system that helps developers quickly plan and execute coding projects with structured work breakdown and autonomous agent coordination.

## Objectives

- [ ] Build work orchestration system with IndyDevDan's patterns
- [ ] Integrate Cascade VSCode extension for work item management
- [ ] Create adapter system for external project management tools
- [ ] Enable async-first agent execution
- [ ] Provide observable progress tracking

## Scope

- Work item planning and breakdown (Cascade format)
- Async task orchestration with HOP/LOP pattern
- Integration with external systems (ADO, GitHub, Jira)
- Real-time progress monitoring
- Agent coordination and delegation

## Success Criteria

- [ ] Can plan work items from description to atomic tasks
- [ ] Can execute work items with async agent delegation
- [ ] External adapters can import/export work items
- [ ] Progress visible at all hierarchy levels
- [ ] System follows IndyDevDan's orchestration principles
